# Security Policy / Политика безопасности

**English.** Please do not report security vulnerabilities in public issues. Use GitHub's private reporting: Security tab → "Report a vulnerability". Cibitube stores your account cookies locally, so reports about credential handling are especially welcome. Only the latest release is supported.

**Русский.** Пожалуйста, не сообщайте об уязвимостях в публичных issues. Используйте приватную отправку GitHub: вкладка Security → «Report a vulnerability». Cibitube хранит куки вашего аккаунта локально, поэтому сообщения о хранении и передаче учётных данных особенно важны. Поддерживается только последний релиз.
